# Season is a Christmas winter, not a calendar year

The hunt is discarded Christmas trees. 26 December and 4 January are the same season; a calendar `year` splits them. A Season is the winter after a Christmas, labeled by that Christmas's year. 4 January 2027 is season 2026. Dates inside 1 December–15 February belong to that hunt. Dates outside the window belong to the upcoming Christmas so off-season logging and testing still work. Recap only applies to winters already finished — an upcoming season stays live so leftover inventory is not thrown away.

We rejected calendar year (what the code did), labeling the winter by January, and admin-defined open/close dates. Existing January rows stored as `entry_date.year` belong to the previous Christmas and must move.
