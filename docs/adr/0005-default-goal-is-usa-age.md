# Default season goal is the age of the USA that winter

The bonfire target is ceremonial, not negotiated: season 2025 was 250, 2026 is 251. The default is `season.year + 1 − 1776` so it ticks up without anyone setting it. A stored SeasonGoal is only an override.

We rejected leaving the goal blank until an admin types it, and rejected using calendar-year USA age (`year − 1776`), which would have kept 2026 at 250 after the hunt moved to Christmas-winter seasons.
